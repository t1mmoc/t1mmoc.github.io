① 生成密钥 （web 流程 · 免 author token）

填加密块 id（可留空自动生成 ULID）与允许解锁的 GitHub 用户名，点按即由服务端生成密钥并写入 KV。

把该 JSON 交给 author.mjs --key-json 本地加密即可。

② 文章管理

查看已注册的加密文章、增删其 ACL 读者、或手动注册/迁移。

注册新文章（密钥由发布工具生成；正常发文请用 author 工具，此表单用于手动注册/迁移）

③ 好友名单 （手动 · 实时生效）

手动指定「朋友」（不在 org 里的人也能享受 acg 背景池）。添加后立即生效，无需对方重新登录。

④ 读者名册 （自动汇总）

由各文章 ACL 中的读者去重派生，纯前端浏览器内计算，不单独存储。
